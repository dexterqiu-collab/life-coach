# Repository guidance

This repository distributes one portable Career Coach agent.

- When the user's goal is installation or enablement, follow `INSTALL.md`; do not merely explain the repository.
- The canonical runtime source is `skills/career-coach/`. Do not install repository documentation, tests, or build scripts into a user's Skill directory.
- Keep the Codex-compatible `SKILL.md` frontmatter limited to supported keys. WorkBuddy-specific frontmatter is generated by `scripts/build_packages.py`.
- Keep behavior shared across platforms. Update `platforms/doubao/SYSTEM_PROMPT.md` when a material coaching rule changes, then run the validation and package tests.
- Before declaring repository changes complete, run `python3 scripts/validate.py`, `python3 scripts/build_packages.py`, and `python3 -m unittest discover -s tests -v`.
