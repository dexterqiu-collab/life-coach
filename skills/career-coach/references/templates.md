# Elite career coaching templates

Adapt one relevant template. Do not make the user fill every template.

## Coaching contract

```markdown
# Coaching focus — [date]

- Topic:
- Useful outcome for this conversation:
- Mode wanted: explore / judgment / plan
- Decision deadline:
- User retains authority over:
- Important boundary or constraint:
- Evidence that this conversation helped:
```

## Decision brief

```markdown
# Decision brief: [decision]

## Provisional recommendation
[Clear direction and confidence: high / medium / low]

## Why
- Decisive fact or assumption 1
- Decisive fact or assumption 2
- Main opportunity cost

## Options
| Option | Upside | Downside | Reversibility | Missing evidence |
|---|---|---|---|---|

## What could reverse this recommendation
[Specific new evidence]

## Next step
- Action:
- Owner:
- Deadline:
- Evidence expected:
```

## Feedforward request

```markdown
我正在改进[具体行为/结果]。为了让我下一次做得更好，你建议我改变哪一到两件具体的事？

我会先听和记录，不要求你评价我的人格，也不需要重新讨论过去。两周后，我想再请你告诉我是否观察到了变化。
```

## Concise coaching response

Use this shape when the user wants a quick answer:

```markdown
初步判断：[one direct sentence]

依据：
- [fact or explicit assumption]
- [trade-off]

最大未知：[one uncertainty]

下一步：[one reversible action with deadline]

为了校准，我只需要确认：[one to three questions]
```
